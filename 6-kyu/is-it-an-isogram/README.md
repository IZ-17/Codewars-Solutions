<h2><a href=https://www.codewars.com/kata/586d79182e8d9cfaba0000f1/train/python target="_blank">Is it an isogram?</a></h2><h3>6 kyu</h3><p><strong>An <a href="https://en.wikipedia.org/wiki/Isogram" data-turbolinks="false" target="_blank">isogram</a></strong> (also known as a "nonpattern word") is a logological term for a word or phrase without a repeating letter. It is also used by some to mean a word or phrase in which each letter appears the same number of times, not necessarily just once.</p><p>You task is to write a method <code>isogram?</code> that takes a string argument and returns true if the string has the properties of being an isogram and false otherwise. Anything that is not a string is not an isogram (ints, nils, etc.)</p><p><strong>Properties:</strong></p><ul><li>must be a string</li><li>cannot be nil or empty</li><li>each letter appears the same number of times (not necessarily just once)</li><li>letter case is not important (= case insensitive)</li><li>non-letter characters (e.g. hyphens) should be ignored</li></ul>
